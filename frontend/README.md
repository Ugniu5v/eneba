# Eneba Market frontend

Next.js 16 + React 19 + TypeScript + Tailwind CSS 4 frontend for the marketplace.

See the project-level [README](../README.md) for setup, architecture, demo
credentials, tests and deployment instructions.

```bash
npm install
npm run dev
```

The app expects the Go API on `http://127.0.0.1:8080`. Set `BACKEND_URL` to point
the `/api` BFF proxy at a different backend.
